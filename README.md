# Fitnes — лендинг

Продающий лендинг приложения Fitnes. Хостится на GitHub Pages, домен **https://fitnes.in.ua**.

- `index.html` — страница (самодостаточная, украинская).
- `assets/` — логотип и favicon.
- `CNAME` — кастомный домен для Pages.

Источник также в основном репозитории `fitnes` (`landing/`). Этот репозиторий — деплой на Pages.
